# Word Reader · 单词与句子学习器

内网本地运行的网页工具，用于**学习英语**。无需注册、无需数据库，数据全部保存在浏览器本地（localStorage）并**不上传任何网络**。手机与电脑同一 WiFi 即可使用。

## 功能

- 📚 **单词 / 句子**：单元式学习，一页一张卡片。
- 🔊 **正宗发音（edge-tts）**：用微软 AI 神经语音合成的 mp3 播放，发音接近母语真人；点击卡片/单词即可朗读。
- 🐢 **语速调节**：很慢 / 慢 / 正常 / 快，一键切换，记住设置。
- 📄 **句子模式**：整句显示翻译；把句子拆成单词块，**点单个单词**可看中文释义、单独朗读；也可整句朗读。
- 🎧 **离线可用**：音频由电脑本地 edge-tts 生成，手机只负责播放，微信内置浏览器也能发声。

## 一键启动（推荐）

双击项目目录下的 **`start.bat`**：

1. 自动检查并安装依赖（`edge-tts`、`pystray`）。
2. 启动内网 HTTP 服务。
3. 任务栏右下角出现 **Word Reader 图标**，右键可：
   - 🌐 打开网页（默认浏览器打开本机页面）
   - 📋 复制访问地址（复制 `http://IP:8000`）
   - 🖥 查看本机 IP（显示局域网访问地址）
   - ⏹ 停止服务

之后浏览器访问：
- 本机：`http://127.0.0.1:8000`
- 手机同 WiFi：`http://<电脑IP>:8000`（IP 用 `ipconfig` 查看，或右键托盘图标查看）


## CSV 格式

单词表：`单词,音标,释义,例句`
```
apple,/ˈæpl/,苹果,I eat an apple.
```
句子表：`句子,翻译`
```
He plays me the pipa. He plays very loud.,他给我弹琵琶。他弹得很大声。
```

> 若句子本身含英文逗号（如 `Yes, he is.`），请给该列加英文双引号包裹：
> `"Yes, he is.",是的，他是。`
> 避免被当成列分隔符导致解析错位。第一行可以是表头（自动识别，列名任意排列都可映射）。

## 使用提示

- **需要电脑能联网**：edge-tts 在电脑合成语音，手机仅播放；断网时语音不可用。
- 首次点某个词会约 1 秒生成，之后自动缓存秒播。
- 数据在浏览器 localStorage，换设备/清理浏览器会丢失，建议定期导出。
- 刷新页面：`Ctrl+Shift+R`（强制加载最新页面）。
