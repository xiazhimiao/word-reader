# Word Reader · 单词&句子管理器

内网本地运行的纯前端网页工具，用于**学习英语**的单词 / 句子管理。无需后端、无需登录、全部数据保存在浏览器本地（localStorage），**不上传任何网络**。

## 功能特性

- 📚 **词库管理**：单词列表 + 搜索 + 按类型（单词/句子）筛选 + 按添加时间分类（今天 / 本周 / 本月 / 更早）。
- 🔊 **文本朗读**：调用浏览器原生 Web Speech API（SpeechSynthesis）朗读单词/例句/句子，支持语速调节，无需网络。
- 🃏 **卡片记忆**：抽认卡模式，点击卡片翻转看释义，可对其标记「认识 / 陌生」，支持「仅不熟悉」复习。
- ✅ **抽查测验**：离线生成选择题（看单词选释义 / 看释义选单词），自动统计正确率、汇总错题。
- 📥 **数据导入**：支持导入 CSV（单词,音标,释义,例句），或手动输入单词/句子；支持导出 JSON 备份。
- 📱 **手机友好**：同一 WiFi 下手机浏览器访问电脑内网 IP 即可使用。

## 快速启动

项目无构建依赖，任意静态服务器均可运行。推荐用 Python：

```bash
cd word-reader-web
python -m http.server 8000
```

然后浏览器打开：

- 本机：`http://127.0.0.1:8000`
- 局域网手机：找到电脑内网 IP（Windows 用 `ipconfig` 查看 IPv4，如 `192.168.1.10`），在手机浏览器访问 `http://192.168.1.10:8000`

> 也可用 vite：`npx vite` 启动。

## CSV 格式说明

最多 5 列：`单词,音标,释义,例句,例句翻译`。第一行可以是表头（自动识别），推荐使用 UTF-8 编码。

```
apple,/ˈæpl/,苹果,I eat an apple.
book,/bʊk/,书,This book is interesting.
```

也可以在「导入/设置 → 手动添加」直接输入。

## 使用提示

- 发音依赖操作系统的语音包；Windows 一般自带英文语音，若无声，可在朗读设置里切换语言或语速。
- 数据只存于当前浏览器，换设备/清理浏览器会丢失，建议使用「导出数据」定期备份。
- Clear（清空全部数据）不可恢复，请谨慎操作。
